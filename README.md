# Golf Swing Analysis
## Application
This is a web application that allows users to upload a video of their golf swing and then get feedback on that swing. The general goals of the application are as follows (crossed out means done):
* Guest website use
* User login
* Ability to analyze swing on a web application
* ~~Swing segmentation model~~
* General swing analysis model
* User specific swing analysis model
* More golf stuff later down the line (scorecards, etc.)
